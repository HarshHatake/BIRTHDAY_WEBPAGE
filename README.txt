SAKSHI BIRTHDAY WEBSITE — GITHUB PAGES

1. Upload index.html and the assets folder to the ROOT of your GitHub repository.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait a minute or two. GitHub will show the published website URL on the Pages settings screen.

The website is static and mobile-friendly. No secrets or private credentials are included.
